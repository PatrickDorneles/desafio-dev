# 🎨 Documentação da UI

Frontend Next.js da aplicação de movimentações financeiras.

## Stack

- **Next.js 15** (App Router) + **React 19**
- **Tailwind CSS 4**
- TypeScript

## Como rodar

```bash
npm install
npm run dev             # dev → http://localhost:3000
npm run build && npm run start
```

## Variáveis de ambiente

- `NEXT_PUBLIC_API_URL` — URL base da API (ver `.env.example`).
