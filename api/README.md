# API — NestJS

Backend da aplicação de **movimentações financeiras** (desafio técnico).

- **Stack:** NestJS 11 · Fastify · TypeScript · Swagger
- **Rodar:** `npm install` → `npm run start:dev` (porta `3001`, configurável via `PORT`)
- **Swagger:** `http://localhost:3001/swagger`
- **Testes:** `npm test` (unit) · `npm run test:e2e`

📚 Documentação detalhada em [`docs/`](./docs/) e na raiz do projeto ([`docs/`](../docs/)).
